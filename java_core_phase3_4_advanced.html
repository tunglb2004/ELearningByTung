⚠️ Exception Handling - Xử Lý Lỗi

Exception là lỗi xảy ra khi chương trình chạy. Nếu không xử lý, chương trình crash. Exception Handling cho phép xử lý lỗi gracefully.

Hai loại exceptions:

  • Checked: Phải handle (FileNotFoundException, IOException)
  • Unchecked: Không bắt buộc (NullPointerException, ArithmeticException)

Try-Catch-Finally Flow:

try { risky code }
↓ (exception?) ↓
catch { handle exception }
↓
finally { cleanup }

Ví dụ:

try { int result = 10 / 0; // ArithmeticException } catch (ArithmeticException e) { System.out.println("Error: " + e.getMessage()); } finally { System.out.println("Cleanup resources"); } // Custom exception public class InvalidTestDataException extends Exception { public InvalidTestDataException(String message) { super(message); } } // Throw exception if (age < 0) { throw new InvalidTestDataException("Age cannot be negative"); }

Best practice: Catch specific exceptions, log them, take screenshots on failure, cleanup resources trong finally block.

🔊 "Exception Handling giúp chương trình không crash. Dùng try-catch-finally để log lỗi, chụp screenshot khi test fail, và cleanup trong finally."

⚡ Streams & Lambda - Functional Programming

Lambda là anonymous functions, viết ngắn gọn. Streams là fluent API để process collections.

Lambda syntax:
(parameters) -> body
Ví dụ: x -> x * 2, (a, b) -> a + b

Stream operations:

// Filter List<Integer> evens = numbers.stream() .filter(n -> n % 2 == 0) .collect(Collectors.toList()); // Map List<String> strings = numbers.stream() .map(n -> "Number: " + n) .collect(Collectors.toList()); // Reduce int sum = numbers.stream() .reduce(0, (a, b) -> a + b); // Chain List<Integer> result = numbers.stream() .filter(n -> n > 3) .map(n -> n * n) .filter(n -> n < 60) .collect(Collectors.toList()); // Real testing example Map<String, List<TestResult>> byStatus = results.stream() .collect(Collectors.groupingBy(r -> r.getStatus())); List<String> failedTests = results.stream() .filter(r -> r.getStatus().equals("FAIL")) .map(r -> r.getTestName()) .collect(Collectors.toList());

Lợi ích: Code ngắn gọn, readable, functional style, dễ parallelize.

🔊 "Lambda và Stream API giúp filter, map, reduce trên collection — lọc test fail, group theo status, transform data trước assert."

📁 File I/O - Đọc/Ghi Files

File I/O dùng để đọc test data từ files hoặc ghi test results.

Read file:

// Simple way Path path = Paths.get("testdata.csv"); List<String> lines = Files.readAllLines(path); // Efficient way try (BufferedReader reader = new BufferedReader( new FileReader("testdata.csv"))) { String line; while ((line = reader.readLine()) != null) { process(line); } }

Write file:

// Write (overwrite) Files.write(Paths.get("output.txt"), content.getBytes()); // Append Files.write(Paths.get("output.txt"), content.getBytes(), StandardOpenOption.APPEND); // Write List List<String> lines = Arrays.asList("line1", "line2"); Files.write(Paths.get("output.txt"), lines);

Parsing test data:

// Parse CSV List<String> lines = Files.readAllLines(path); List<Map<String, String>> testCases = lines.stream() .skip(1) // Skip header .map(line -> { String[] parts = line.split(","); return new HashMap<>() {{ put("username", parts[0]); put("password", parts[1]); }}; }) .collect(Collectors.toList());
🔊 "File I/O đọc CSV test data và ghi báo cáo. Dùng try-with-resources để đóng stream an toàn."

📝 String Methods - Manipulate Strings

String methods rất useful untuk parse responses, verify messages, build test data.

Common methods:

// Case conversion text.toUpperCase(); text.toLowerCase(); // Trimming text.trim(); // Remove leading/trailing spaces // Searching text.contains("keyword"); text.startsWith("Start"); text.endsWith("End"); text.indexOf("text"); // Return position or -1 // Replacing text.replace("old", "new"); // Splitting String[] parts = csv.split(","); // Substring text.substring(0, 5); // Get first 5 chars // Comparison text.equals("exact"); text.equalsIgnoreCase("EXACT"); text.compareTo(other); // -1, 0, or 1

StringBuilder - Efficient concatenation:

// Bad (slow) String result = ""; for (int i = 0; i < 1000; i++) { result += i; // Create new string each time } // Good (fast) StringBuilder sb = new StringBuilder(); for (int i = 0; i < 1000; i++) { sb.append(i); } String result = sb.toString();

Trong testing: Parse API responses, verify messages, build CSV reports, extract values from text.

🔊 "String methods: trim, contains, split, replace khi verify UI; StringBuilder khi nối chuỗi trong vòng lặp."
