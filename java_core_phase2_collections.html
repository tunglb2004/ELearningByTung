List · Set · Map — Collections Framework

🏠 Trang chủ

👋 Collections Framework

Collections giúp bạn lưu trữ và manipulate tập hợp các objects. Thay vì arrays cố định kích thước, Collections cho phép dynamic size. Framework cung cấp 3 interface chính: List, Set, Map, mỗi loại có multiple implementations.

📚 Mục Tiêu Học Tập

  • Hiểu List - Ordered, có index, cho phép duplicate
  • Học Set - Unordered, unique values
  • Nắm Map - Key-value pairs, fast lookup
  • Biết khi nào dùng cái nào
  • Áp dụng trong automation testing
🔊 "Chào mừng đến với phần Collections trong Java Core. Collections Framework giúp bạn lưu trữ và xử lý tập hợp dữ liệu linh hoạt hơn mảng cố định. Trong bài này chúng ta học List cho dữ liệu có thứ tự, Set cho giá trị duy nhất, và Map cho cặp khóa-giá trị."

📋 List - Danh Sách Có Thứ Tự

List là ordered collection, có thể truy cập qua index (0-based), cho phép duplicate values.

Implementation chính:
  • ArrayList: Dynamic array, fast access by index O(1)
  • LinkedList: Linked list, fast insert/delete O(1), slow access O(n)

Phương thức chính:

List<String> list = new ArrayList<>(); list.add("Item1"); // Thêm element list.add(0, "Item0"); // Chèn tại index list.get(0); // Lấy element tại index list.remove("Item1"); // Xóa element list.size(); // Lấy số elements list.contains("Item1"); // Kiểm tra có chứa list.clear(); // Xóa tất cả // Loop for (String item : list) { } for (int i = 0; i < list.size(); i++) { }

Khi dùng List: Test data tuần tự, test cases phải chạy theo thứ tự, results cần preserve thứ tự.

🔊 "List là collection có thứ tự, truy cập theo index và cho phép trùng lặp. ArrayList phù hợp truy cập nhanh theo index, LinkedList phù hợp chèn xóa nhiều."

🎯 Set - Tập Hợp Unique Values

Set là unordered collection, không cho phép duplicate, dùng để kiểm tra unique values nhanh.

Implementation chính:
  • HashSet: Hash table, O(1) lookup, unordered
  • TreeSet: Sorted set, O(log n) lookup, ordered
  • LinkedHashSet: Preserve insertion order

Phương thức chính:

Set<String> set = new HashSet<>(); set.add("Chrome"); // Return true nếu thêm được, false nếu duplicate set.remove("Chrome"); // Xóa element set.size(); // Lấy số elements set.contains("Chrome"); // Kiểm tra có chứa set.clear(); // Xóa tất cả // Set operations set.addAll(otherSet); // Union set.retainAll(otherSet); // Intersection set.removeAll(otherSet); // Difference

Khi dùng Set: Unique browsers, unique test IDs, unique usernames, ensure không có duplicates.

🔊 "Set không cho phép phần tử trùng. Dùng Set khi cần danh sách browser duy nhất, test ID không trùng, hoặc kiểm tra nhanh phần tử đã tồn tại."

🗝️ Map - Key-Value Pairs

Map lưu key-value pairs, keys unique, values có thể duplicate, O(1) lookup by key.

Implementation chính:
  • HashMap: Hash table, O(1) lookup, unordered
  • TreeMap: Sorted by key, O(log n) lookup
  • LinkedHashMap: Preserve insertion order

Phương thức chính:

Map<String, Integer> map = new HashMap<>(); map.put("key", value); // Thêm/update entry map.get("key"); // Lấy value (null nếu không có) map.getOrDefault("key", 0); // Get hoặc default value map.remove("key"); // Xóa entry map.size(); // Lấy số entries map.containsKey("key"); // Kiểm tra key map.containsValue(value); // Kiểm tra value map.keySet(); // Lấy tất cả keys map.values(); // Lấy tất cả values map.entrySet(); // Lấy tất cả key-value pairs // Loop through Map for (Map.Entry<String, Integer> entry : map.entrySet()) { String key = entry.getKey(); Integer value = entry.getValue(); }

Khi dùng Map: Test data (username => password), locators (button => By.id), test results (testname => status), configuration.

🔊 "Map lưu cặp key-value với key duy nhất. HashMap tra cứu O(1) phù hợp lưu locator, cấu hình username-password, hoặc map tên test sang trạng thái."

⚖️ So Sánh List vs Set vs Map

Đặc điểm List Set Map
Thứ tự ✅ Có (Ordered) ❌ Không (Unordered) ❌ Không
Duplicate ✅ Cho phép ❌ Không ❌ Keys unique, values OK
Truy cập By index By object By key
Performance Get: O(1), Add/Remove middle: O(n) Add/Remove/Contains: O(1) Get/Put/Remove: O(1)
Dùng khi Cần thứ tự, sequential data Cần unique, cần fast lookup Cần key-value pairs, fast lookup

💡 Ví Dụ Thực Tế Trong Automation Testing

// Test data List<Map<String, String>> testCases = new ArrayList<>(); testCases.add(new HashMap<>() {{ put("username", "john"); put("password", "pass123"); put("expected", "Login Success"); }}); // Browsers to test Set<String> browsers = new HashSet<>(); browsers.add("Chrome"); browsers.add("Firefox"); browsers.add("Safari"); // Page locators Map<String, String> locators = new HashMap<>(); locators.put("loginButton", "By.id('login')"); locators.put("usernameInput", "By.name('username')"); locators.put("passwordInput", "By.name('password')"); // Test results Map<String, String> results = new HashMap<>(); for (Map<String, String> testCase : testCases) { for (String browser : browsers) { String testName = testCase.get("username") + "_" + browser; String result = runTest(testCase, browser, locators); results.put(testName, result); // "john_Chrome" => "PASS" } }
🔊 "So sánh List, Set và Map: List có thứ tự và cho duplicate; Set unique; Map tra cứu theo key. Trong framework test, thường kết hợp cả ba."

🎓 Recap

List, Set, Map là 3 collections chính. Chọn đúng cái cho đúng situation: List cho ordered data, Set cho unique values, Map cho key-value lookups. Trong automation testing, combine cả 3: List lưu test cases, Set lưu unique browsers, Map lưu locators và results.
