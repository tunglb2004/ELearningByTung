🔧 Selenium WebDriver Là Gì?

Selenium = Công Cụ Tự Động Điều Khiển Browser

Selenium WebDriver cho phép bạn viết code để tự động điều khiển browser (Chrome, Firefox, Safari, Edge).

Mà Không Cần Người Can Thiệp

WebDriver sẽ:

  • ✅ Mở browser tự động
  • ✅ Navigate tới websites
  • ✅ Tìm elements trên page
  • ✅ Tương tác với elements (click, type, submit)
  • ✅ Kiểm tra kết quả
  • ✅ Đóng browser

Kiến Trúc Selenium

Test Code (Java) ↓ Selenium WebDriver ↓ Browser Driver (ChromeDriver, GeckoDriver, etc.) ↓ Browser (Chrome, Firefox, Safari)

Tại Sao Dùng Selenium?

  • ✅ Open Source: Miễn phí, code mở
  • ✅ Multi-Language: Java, Python, C#, JavaScript
  • ✅ Multi-Browser: Chrome, Firefox, Safari, Edge
  • ✅ Popular: Dùng bởi hàng triệu testers
  • ✅ Powerful: Có thể automate hầu hết UI interactions

🔍 Locators - Cách Tìm Elements

Locator Là Gì?

Locator = cách để Selenium tìm elements trên page

Ví dụ: Tìm cái textbox "search" để gõ dữ liệu vào

8 Loại Locators

  • 1️⃣ ID - By.id("element_id")
  • 2️⃣ Name - By.name("element_name")
  • 3️⃣ Class Name - By.className("element_class")
  • 4️⃣ Tag Name - By.tagName("button")
  • 5️⃣ CSS Selector - By.cssSelector("div.button")
  • 6️⃣ XPath - By.xpath("//button[@id='submit']")
  • 7️⃣ Link Text - By.linkText("Click Here")
  • 8️⃣ Partial Link Text - By.partialLinkText("Click")

Thứ Tự Ưu Tiên

  1. 🥇 ID (nhanh, unique)
  2. 🥈 Name (tốt nếu element có name)
  3. 🥉 CSS Selector (mạnh, dễ maintain)
  4. ❌ XPath (cuối cùng, dễ break)
💡 Best Practice: Dùng ID nếu có. Nếu không có ID, dùng CSS Selector. XPath là last resort.
🔊 "Mở website chỉ là step đầu tiên. Tiếp theo bạn cần tìm các elements như button, input field, text, v.v. Selenium cung cấp method findElement() để tìm element. Nhưng tìm bằng cách nào? Có 8 loại locators. Locator thứ nhất là ID. Nếu element có id='submit-btn', bạn dùng By.id('submit-btn'). ID là locator tốt nhất vì ID phải unique - chỉ có 1 element có ID đó. Locator thứ hai là NAME. Nếu input field có name='username', bạn dùng By.name('username'). Loại thứ ba là CLASS_NAME. Nếu element có class='btn btn-primary', bạn dùng By.className('btn-primary'). Loại thứ tư là TAG_NAME. Nếu bạn muốn tìm tất cả button elements, dùng By.tagName('button'). Loại thứ năm là CSS_SELECTOR. CSS selector là powerful, ví dụ By.cssSelector('div.container > button.submit'). Loại thứ sáu là XPATH - X Path expression, rất powerful nhưng complex, ví dụ By.xpath('//button[@id="submit"]'). Loại thứ bảy là LINK_TEXT. Nếu bạn muốn tìm link bằng text, dùng By.linkText('Click here'). Loại thứ tám là PARTIAL_LINK_TEXT. Nếu link text là 'Click here for details', bạn dùng By.partialLinkText('Click here'). Best practice là ID nếu có, vì ID cực nhanh. Nếu không có ID, dùng Name. Nếu không có Name, dùng CSS selector hay XPath. Tránh dùng By.tagName() vì nó quá generic - nếu có 100 buttons, nó sẽ find tất cả."

🔍 Locators: ID & Name

1. By ID - Nhanh & Reliable

Dùng attribute id của element

<input type="text" id="username" placeholder="Enter username">
// Cú pháp WebElement element = driver.findElement(By.id("username")); // Điền username element.sendKeys("user123"); // Hoặc shorthand driver.findElement(By.id("username")).sendKeys("user123");

2. By Name - Cũng Tốt

Dùng attribute name của element

<input type="password" name="pass" placeholder="Enter password">
// Cú pháp WebElement element = driver.findElement(By.name("pass")); // Điền password element.sendKeys("password123");

Ưu & Nhược Điểm

Locator Ưu Điểm Nhược Điểm
ID ✅ Nhanh, Unique, Reliable ❌ Phải có ID attribute
Name ✅ Đơn giản, Hay có ❌ Không unique (nhiều element cùng name)
🔊 "Hãy xem code để find element. Import By từ org.openqa.selenium. Tạo WebDriver instance. Navigate đến URL. Bây giờ find element bằng ID: WebElement usernameField = driver.findElement(By.id('username')). Nếu element tồn tại, method return WebElement object. Nếu không tìm thấy, throw NoSuchElementException. Vì vậy thường viết trong try-catch block. Hoặc dùng WebDriverWait để wait cho element appear - chúng ta sẽ học sau. Find bằng name: WebElement passwordField = driver.findElement(By.name('password')). Find bằng CSS selector: WebElement loginButton = driver.findElement(By.cssSelector('button.login-btn')). Find bằng XPath: WebElement submitButton = driver.findElement(By.xpath('//button[@type="submit"]')). XPath là powerful vì có thể select element bằng text, attribute, position, v.v. Ví dụ xpath('//button[text()="Login"]') sẽ find button có text là 'Login'. XPath có 2 loại: relative XPath hay absolute XPath. Relative tốt hơn vì nó không phụ thuộc vào structure hoàn toàn. Ví dụ '//button' là relative, '/html/body/div/button' là absolute."

🔍 Locators: CSS & XPath

5. By CSS Selector - Flexible & Powerful

Dùng CSS selectors để tìm elements

CSS Selector Syntax:

/* Tìm theo class */ By.cssSelector(".login-button") By.cssSelector("button.btn-primary") /* Tìm theo attribute */ By.cssSelector("input[type='password']") By.cssSelector("input[name='email']") /* Tìm parent > child */ By.cssSelector("div.form > input") /* Tìm theo text */ By.cssSelector("button:contains('Login')")

6. By XPath - Mạnh Nhất

Dùng XPath (XML Path Language) - rất mạnh

XPath Syntax:

/* Tìm button có id='submit' */ //button[@id='submit'] /* Tìm input có type='password' */ //input[@type='password'] /* Tìm button có text chứa 'Login' */ //button[contains(text(),'Login')] /* Tìm element thứ 2 */ (//button)[2] /* Tìm button là child của form */ //form//button

Ví Dụ So Sánh

Locator CSS XPath
Tìm button class="login" button.login //button[@class='login']
Tìm input type="email" input[type='email'] //input[@type='email']
Tìm thẻ button chứa "Sign" ❌ Khó ✅ //button[contains(text(),'Sign')]
⚠️ Cảnh báo: Tránh XPath quá phức tạp. Nếu HTML thay đổi, XPath sẽ break. Dùng XPath là last resort.
🔊 "CSS selector hay XPath, cái nào tốt hơn? CSS selector thường nhanh hơn XPath vì browser native hỗ trợ CSS selector. XPath powerful hơn nhưng slow hơn. Ví dụ, find button với text 'Submit' bằng CSS selector khó, nhưng XPath là //button[text()='Submit']. Find button với class 'btn-primary' bằng CSS selector dễ, button.btn-primary. Best practice là dùng CSS selector khi có thể, dùng XPath khi cần. Không dùng absolute XPath vì nó brittle - nếu HTML structure change, nó break. Ví dụ, /html/body/div[1]/div[2]/button - nếu add một div, path này break rồi. Dùng relative XPath // để find element dù nó ở đâu. Hoặc dùng CSS selector div.container > button.submit - cũng flexible. Pro tip: mở Chrome DevTools (F12), right-click element, chọn 'Inspect', rồi right-click element trong DevTools, chọn 'Copy full XPath' hoặc 'Copy selector' để generate XPath hay CSS selector automatically."

🔊 "Sau khi tìm element, bạn cần tương tác với nó. Tương tác thứ nhất là CLICK. usernameField.click() sẽ click vào element đó. Tương tác thứ hai là SENDKEYS. usernameField.sendKeys('john@example.com') sẽ gõ text vào input field. Bạn có thể gõ bình thường text hoặc dùng Keys enum để send special keys. Ví dụ sendKeys('text', Keys.TAB) sẽ gõ 'text' rồi nhấn Tab. sendKeys(Keys.ENTER) sẽ nhấn Enter. sendKeys(Keys.CONTROL, 'A') sẽ select all (Ctrl+A). Tương tác thứ ba là CLEAR. usernameField.clear() sẽ xóa hết text trong input field. Tương tác thứ tư là SUBMIT. loginForm.submit() sẽ submit form - đó là equivalent của click submit button. Tương tác thứ năm là GETTEXT. String text = element.getText() sẽ lấy text content của element. Ví dụ lấy text của success message sau login. Tương tác thứ sáu là GETATTRIBUTE. String value = element.getAttribute('href') sẽ lấy attribute của element. Ví dụ lấy href attribute của link. Tương tác thứ bảy là ISDISPLAYED. boolean displayed = element.isDisplayed() check element có visible không. Tương tác thứ tám là ISENABLED. boolean enabled = element.isEnabled() check element có enable không (button có thể disabled). Tương tác thứ chín là ISSELECTED. boolean selected = element.isSelected() check checkbox/radio có selected không."

👆 Element Interactions

WebElement Methods - Tương Tác Với Elements

Sau khi tìm element, bạn có thể tương tác:

1. sendKeys() - Gõ Text

// Gõ text vào textbox WebElement username = driver.findElement(By.id("username")); username.sendKeys("john_doe"); // Gõ multiple lines username.sendKeys("user", "name"); // Gõ dặc biệt keys (Enter, Tab, Delete) username.sendKeys(Keys.ENTER); // Nhấn Enter username.sendKeys(Keys.TAB); // Nhấn Tab

2. click() - Click Element

// Click button WebElement loginBtn = driver.findElement(By.id("login-btn")); loginBtn.click(); // Double click (advanced) Actions actions = new Actions(driver); actions.doubleClick(loginBtn).perform();

3. clear() - Xóa Text

// Xóa text trong textbox WebElement username = driver.findElement(By.id("username")); username.clear(); // Xóa sạch // Vẫn cách: select all rồi delete username.sendKeys(Keys.chord(Keys.CONTROL, "a")); username.sendKeys(Keys.DELETE);

4. submit() - Submit Form

// Submit form WebElement form = driver.findElement(By.id("login-form")); form.submit(); // Hoặc click submit button driver.findElement(By.id("submit-btn")).click();
🔊 "Một vấn đề lớn khi automate browser là TIMING. Page load không instantaneous. Element có thể load chậm vì network slow. Nếu bạn cố click element trước nó load, bạn sẽ get NoSuchElementException. Selenium cung cấp 2 loại waits. Loại thứ nhất là IMPLICIT WAIT. Bạn set một global timeout, ví dụ driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10)). Khi bạn findElement(), nếu element không exist, thay vì fail ngay, Selenium sẽ wait tối đa 10 giây, nếu element appear trong 10 giây, nó return element, nếu sau 10 giây element vẫn không appear, nó throw NoSuchElementException. Implicit wait áp dụng cho tất cả findElement() calls. Nhưng implicit wait có problem: nó wait cho tất cả elements, kể cả elements không quan trọng. Nếu element không exist, nó vẫn wait full 10 giây rồi throw exception, lãng phí time. Loại thứ hai là EXPLICIT WAIT - TỐT HƠN. WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10)). Rồi bạn wait() cho condition cụ thể. Ví dụ, wait.until(ExpectedConditions.visibilityOfElementLocated(By.id('success-msg'))). Cái này sẽ wait tối đa 10 giây, nhưng chỉ chờ cho element cụ thể visible. Nếu element appear sau 2 giây, nó immediately return, không chờ full 10 giây. Explicit wait cũng chỉ apply cho element cụ thể, không tất cả. Pro tip: dùng explicit waits, không dùng implicit waits. Implicit waits slow vì wait tất cả. Ngoài visibilityOfElementLocated, có nhiều ExpectedConditions khác: elementToBeClickable (element visible và enable), presenceOfElementLocated (element ở DOM dù không visible), textToBePresentInElement (element có specific text), v.v."

📖 Lấy Thông Tin Element

Các Methods Để Lấy Thông Tin

1. getText() - Lấy Text Content

// Lấy text của element WebElement heading = driver.findElement(By.id("page-title")); String text = heading.getText(); System.out.println("Title: " + text); // Verify text assert text.equals("Login Page");

2. getAttribute() - Lấy Attribute

// Lấy attribute value WebElement input = driver.findElement(By.id("email")); String placeholder = input.getAttribute("placeholder"); String type = input.getAttribute("type"); System.out.println("Placeholder: " + placeholder); System.out.println("Type: " + type);

3. isDisplayed() - Kiểm Tra Visible

// Kiểm tra element có hiển thị không WebElement element = driver.findElement(By.id("popup")); if (element.isDisplayed()) { System.out.println("✅ Element visible"); } else { System.out.println("❌ Element hidden"); }

4. isEnabled() - Kiểm Tra Enable

// Kiểm tra button có enabled không WebElement submitBtn = driver.findElement(By.id("submit")); if (submitBtn.isEnabled()) { submitBtn.click(); } else { System.out.println("Button disabled"); }

5. isSelected() - Kiểm Tra Selected

// Kiểm tra checkbox/radio có selected không WebElement checkbox = driver.findElement(By.id("agree")); if (checkbox.isSelected()) { System.out.println("✅ Checkbox checked"); } else { checkbox.click(); // Check nó }
🔊 "Ngoài basic interactions, Selenium cung cấp Advanced Actions. Thứ nhất là HOVER (mouseover). Nếu bạn hover mouse vào element, element có thể show dropdown menu. Dùng Actions class: Actions actions = new Actions(driver); actions.moveToElement(element).perform(). Thứ hai là DRAG AND DROP. Nếu bạn kéo một element sang vị trí khác. actions.dragAndDrop(sourceElement, targetElement).perform(). Thứ ba là RIGHT CLICK. actions.contextClick(element).perform() sẽ right-click element. Thứ tư là KEY COMBINATIONS. actions.sendKeys(Keys.CONTROL, 'A') sẽ select all text. Thứ năm là SCROLL. Nếu element không visible vì nó ở dưới, bạn cần scroll. JavascriptExecutor js = (JavascriptExecutor) driver; js.executeScript('arguments[0].scrollIntoView(true);', element) sẽ scroll element vào view. Hoặc js.executeScript('window.scrollBy(0, 500)') scroll down 500 pixels. Thứ sáu là SWITCH WINDOW. Nếu click link open new window. driver.switchTo().window(windowHandle) switch sang window đó. Thứ bảy là SWITCH FRAME. Nếu element ở trong iframe. driver.switchTo().frame(frameElement) switch vào frame đó."

⏳ Waits - Chờ Elements Load

Tại Sao Cần Waits?

Browser mất thời gian để load page, JS execute, elements render.

Nếu Selenium tìm element trước khi element load xong → NoSuchElementException

Ví Dụ Problem:

driver.get("https://example.com"); // JavaScript tạo element sau 3 giây WebElement elem = driver.findElement(By.id("dynamic")); // ❌ Exception! Element chưa load

3 Cách Waits

  • 1️⃣ Implicit Waits: Chờ toàn bộ findElement calls
  • 2️⃣ Explicit Waits: Chờ specific condition (khuyến cáo)
  • 3️⃣ Fluent Waits: Advanced version của Explicit

Performance So Sánh

Wait Type Tốc Độ Reliability Khi Dùng
Implicit Chậm Thấp ❌ Tránh
Explicit Nhanh Cao ✅ Dùng cái này
Fluent Nhanh Cao ✅ Advanced
🔊 "Best practice khi automate là combine waits với interactions. Không nên dùng Thread.sleep() - đó là hardcoded wait, luôn wait full time dù element appear sớm. Ví dụ, test case: click login button, chờ welcome message appear, lấy text message, verify it contains 'Welcome'. Code sẽ như thế này: driver.get('https://example.com/login'). driver.findElement(By.id('username')).sendKeys('john'). driver.findElement(By.id('password')).sendKeys('pass'). driver.findElement(By.id('login')).click(). Bây giờ bạn cần chờ welcome message appear. Dùng explicit wait: WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10)). WebElement welcomeMsg = wait.until(ExpectedConditions.visibilityOfElementLocated(By.id('welcome'))). String text = welcomeMsg.getText(). Assert.assertTrue(text.contains('Welcome')). Nếu welcome element appear sau 3 giây, wait return immediately, không lãng phí time. Nếu sau 10 giây không appear, throw TimeoutException. Đó là proper way to handle waits."

⏳ Implicit Waits

Implicit Wait Là Gì?

Báo Selenium: "Chờ tối đa 10 giây khi tìm element"

Nếu element tìm được trước 10 giây → trả về ngay (không chờ hết)

Nếu 10 giây hết mà chưa tìm → throw NoSuchElementException

Code Example:

import java.time.Duration; public class ImplicitWaitTest { public static void main(String[] args) { WebDriver driver = new ChromeDriver(); // Set implicit wait = 10 seconds driver.manage().timeouts().implicitlyWait( Duration.ofSeconds(10) ); driver.get("https://example.com"); // Selenium sẽ chờ tối đa 10s WebElement elem = driver.findElement(By.id("dynamic")); driver.quit(); } }

Nhược Điểm

  • ❌ Chờ 10s cho mỗi findElement, dù element có trong 1s
  • ❌ Toàn cục (affect all findElements)
  • ❌ Không thể điều chỉnh per-element
  • ❌ Chậm (giảm execution time)
⚠️ Best Practice: Tránh implicit waits. Dùng explicit waits thay vào.
🔊 "Hãy viết một complete login test flow sử dụng tất cả những gì chúng ta vừa học. Test case: Login with valid credentials. Bước 1: navigate to login page - driver.get('https://example.com/login'). Bước 2: find username field - WebElement usernameField = wait.until(ExpectedConditions.visibilityOfElementLocated(By.id('username'))). Bước 3: type username - usernameField.sendKeys('john@example.com'). Bước 4: find password field - WebElement passwordField = driver.findElement(By.name('password')). Bước 5: type password - passwordField.sendKeys('password123'). Bước 6: find login button - WebElement loginButton = driver.findElement(By.cssSelector('button.login-btn')). Bước 7: click login - loginButton.click(). Bước 8: wait for welcome message - WebElement welcomeMsg = wait.until(ExpectedConditions.visibilityOfElementLocated(By.className('success-message'))). Bước 9: get text - String text = welcomeMsg.getText(). Bước 10: assert - Assert.assertTrue(text.contains('Chào mừng')). Nếu tất cả assert pass, test PASS. Nếu một assert fail, hoặc exception throw, test FAIL. Đó là một complete Selenium test case."

⏳ Explicit Waits (Best Practice)

Explicit Wait Là Gì?

Báo Selenium: "Chờ cho condition cụ thể, tối đa 10 giây"

Ví dụ conditions:

  • ✅ Element present/visible/clickable
  • ✅ Text appears in element
  • ✅ Element disabled
  • ✅ Alert appears

Code Example:

import org.openqa.selenium.support.ui.WebDriverWait; import org.openqa.selenium.support.ui.ExpectedConditions; import java.time.Duration; public class ExplicitWaitTest { public static void main(String[] args) { WebDriver driver = new ChromeDriver(); driver.get("https://example.com"); // Khởi tạo WebDriverWait (10 seconds) WebDriverWait wait = new WebDriverWait( driver, Duration.ofSeconds(10) ); // Chờ element present WebElement elem = wait.until( ExpectedConditions.presenceOfElementLocated( By.id("dynamic") ) ); // Chờ element visible WebElement button = wait.until( ExpectedConditions.visibilityOfElementLocated( By.id("submit") ) ); button.click(); // Chờ element clickable WebElement link = wait.until( ExpectedConditions.elementToBeClickable(By.id("link")) ); link.click(); driver.quit(); } }

Common ExpectedConditions

Condition Nghĩa
presenceOfElementLocated Element có trong DOM (ngay cả khi hidden)
visibilityOfElementLocated Element visible (displayed + enabled)
elementToBeClickable Element visible + enabled + clickable
textToBePresentInElement Element có text nào đó
presenceOfAllElementsLocatedBy Tất cả elements trong list có
✅ Best Practice: Dùng explicit waits. Cụ thể, fail-fast, nhanh.
🔊 "Khi automate, nhiều thứ có thể go wrong. Thứ nhất là NoSuchElementException - element không tìm thấy. Có thể element locator sai, hoặc element chưa load. Dùng explicit wait để avoid này. Thứ hai là TimeoutException - explicit wait timeout. Element không appear trong specified time. Có thể network slow, hoặc element load fail. Thứ ba là StaleElementReferenceException - element reference cũ. Sau khi page refresh, old element reference không valid. Thứ tư là AssertionError - assertion fail. Expected không match actual. Thứ năm là NullPointerException - element null. Tất cả exceptions này nên handle bằng try-catch hoặc test framework. Test framework như TestNG sẽ catch exceptions và mark test as FAILED. Không cần viết try-catch đơn giản để rethrow exception. Nhưng nếu bạn muốn custom error message, viết try-catch. Ví dụ: try { driver.findElement(By.id('login')).click(); } catch (NoSuchElementException e) { System.out.println('Login button not found'); throw new AssertionError('Login button not found', e); }."

🎯 Advanced Actions

Actions Class - Tương Tác Phức Tạp

Untuk interactions ngoài click/type: hover, drag & drop, keys combos

1. Hover Over Element

import org.openqa.selenium.interactions.Actions; // Hover over element WebElement menu = driver.findElement(By.id("dropdown")); Actions actions = new Actions(driver); actions.moveToElement(menu).perform(); // Rồi click submenu WebElement submenu = driver.findElement(By.id("submenu")); submenu.click();

2. Drag & Drop

// Drag element từ A tới B WebElement source = driver.findElement(By.id("box1")); WebElement target = driver.findElement(By.id("box2")); Actions actions = new Actions(driver); actions.dragAndDrop(source, target).perform();

3. Right Click (Context Menu)

// Right click WebElement elem = driver.findElement(By.id("element")); Actions actions = new Actions(driver); actions.contextClick(elem).perform(); // Rồi click menu option driver.findElement(By.xpath("//div[text()='Delete']")).click();

4. Key Combinations

// Ctrl + A (select all) Actions actions = new Actions(driver); actions.keyDown(Keys.CONTROL) .sendKeys("a") .keyUp(Keys.CONTROL) .perform(); // Ctrl + C (copy) actions.keyDown(Keys.CONTROL) .sendKeys("c") .keyUp(Keys.CONTROL) .perform();

5. Scroll

// Scroll to element WebElement elem = driver.findElement(By.id("footer")); ((JavascriptExecutor) driver).executeScript( "arguments[0].scrollIntoView(true);", elem ); // Scroll page ((JavascriptExecutor) driver).executeScript( "window.scrollBy(0, 500);" );
🔊 "Khi viết E2E tests, code có thể get messy nếu bạn mix page interaction logic với test logic. Best practice là PAGE OBJECT MODEL - tách page-specific code sang separate class. Ví dụ, tạo class LoginPage. Ngoài constructor, có private By locators: usernameLocator = By.id('username'), passwordLocator = By.name('password'), loginButtonLocator = By.cssSelector('button.login'). Có public methods: login(String username, String password) - fillUsername(username), fillPassword(password), clickLogin(). Mỗi method wrap page interaction. Test code sẽ clean: loginPage.login('john@example.com', 'password123'). String welcomeMsg = driver.findElement(...).getText(). Assert.assertTrue(...). Nếu locators change, bạn chỉ update LoginPage class, không cần update test code. Chúng ta sẽ deep dive vào POM ở PHASE 3."

🪟 Window & Frame Handling

1. Switch Between Windows

Nếu website mở multiple windows, bạn phải switch

// Lấy current window handle String mainWindow = driver.getWindowHandle(); // Lấy tất cả window handles Set<String> handles = driver.getWindowHandles(); // Switch to another window for (String handle : handles) { if (!handle.equals(mainWindow)) { driver.switchTo().window(handle); System.out.println("Switched to: " + driver.getTitle()); } } // Switch back driver.switchTo().window(mainWindow);

2. Switch to iFrame

iFrame = HTML element chứa document khác

// HTML: <iframe id="payment-frame">...</iframe> // Switch to iframe WebElement iframe = driver.findElement(By.id("payment-frame")); driver.switchTo().frame(iframe); // Bây giờ có thể tìm elements trong iframe WebElement cardNum = driver.findElement(By.id("card-number")); cardNum.sendKeys("1234567890123456"); // Switch back to main content driver.switchTo().defaultContent();

3. Switch to Alert

// Accept alert Alert alert = driver.switchTo().alert(); System.out.println("Alert text: " + alert.getText()); alert.accept(); // Click OK // Dismiss alert alert.dismiss(); // Click Cancel // Type in prompt alert.sendKeys("my answer"); alert.accept();
💡 Tip: Sau khi switch to iframe, phải switchTo().defaultContent() để quay lại main content.
🔊 "PHASE 2 chúng ta đã learn Selenium WebDriver - công cụ chính để automate browser. Chúng ta learn 8 locators (ID, name, className, tagName, cssSelector, xpath, linkText, partialLinkText) với best practice là ID > name > cssSelector > xpath. Chúng ta learn interactions: click(), sendKeys(), clear(), submit(), getText(), getAttribute(), isDisplayed(), isEnabled(), isSelected(). Chúng ta learn waits: implicit (slow, not recommended) vs explicit (fast, recommended với ExpectedConditions). Chúng ta learn advanced actions: hover, drag drop, right click, key combinations, scroll, switch window, switch frame. Chúng ta learn proper error handling: try-catch, explicit waits để avoid exceptions. Chúng ta learn best practice: Page Object Model để keep code clean. Selenium chỉ là tool - nó không manage test cases, assertions, reporting. Đó là lý do tại sao PHASE 3 chúng ta sẽ learn TestNG framework - để structure tests properly."

💻 Real-World Example 1: Login Test

Scenario: Test Login Functionality

Website: https://example.com/login

Login flow: Username → Password → Click Login → Verify welcome message

import org.openqa.selenium.*; import org.openqa.selenium.chrome.ChromeDriver; import org.openqa.selenium.support.ui.*; import org.junit.Test; import org.junit.After; import java.time.Duration; public class LoginTest { WebDriver driver; WebDriverWait wait; @Before public void setUp() { driver = new ChromeDriver(); wait = new WebDriverWait(driver, Duration.ofSeconds(10)); } @Test public void testValidLogin() { // Step 1: Navigate driver.get("https://example.com/login"); // Step 2: Wait & find username input WebElement username = wait.until( ExpectedConditions.visibilityOfElementLocated(By.id("username")) ); username.sendKeys("john@example.com"); // Step 3: Find & fill password WebElement password = driver.findElement(By.id("password")); password.sendKeys("password123"); // Step 4: Click login WebElement loginBtn = driver.findElement(By.id("login-btn")); loginBtn.click(); // Step 5: Wait & verify welcome message WebElement welcome = wait.until( ExpectedConditions.visibilityOfElementLocated(By.id("welcome-msg")) ); // Step 6: Assert String welcomeText = welcome.getText(); assertTrue("Welcome message should appear", welcomeText.contains("Welcome")); } @After public void tearDown() { driver.quit(); } }
OUTPUT: [ChromeDriver] Started 🌐 Navigating to: https://example.com/login 👆 Clicking username field ✍️ Entering username: john@example.com ✍️ Entering password: **** 👆 Clicking login button ⏳ Waiting for welcome message... 💬 Welcome message found: "Welcome, John!" ✅ TEST PASSED Time: 5.2 seconds
🔊 "Khi bạn click link 'Open in new window', browser sẽ open new window. Selenium chạy trên window gốc, nếu bạn cố find element ở new window, nó fail vì Selenium focus vào window gốc. Bạn cần switch sang new window. Đầu tiên get all window handles: Set<String> allHandles = driver.getWindowHandles(). Nó return list of window handles - mỗi handle là unique ID của một window. Rồi loop through handles, switch sang window mới: for (String handle : allHandles) { driver.switchTo().window(handle); if (driver.getTitle().contains('New Page')) { break; } }. Bây giờ bạn đang ở new window, bạn có thể find elements ở page này. Sau khi done, switch back sang original window: driver.switchTo().window(originalHandle). Pro tip: nên store original window handle trước switch, rồi switch back sau."

Scenario: Add Product to Cart

Flow: Search "Laptop" → Find product → View details → Add to cart → Verify cart count

@Test public void testAddToCart() { driver.get("https://ecommerce.com"); // Search for laptop WebElement searchBox = driver.findElement(By.id("search")); searchBox.sendKeys("Laptop"); driver.findElement(By.id("search-btn")).click(); // Wait for search results WebElement product = wait.until( ExpectedConditions.visibilityOfElementLocated( By.xpath("//div[@class='product'][1]") ) ); product.click(); // Verify product page WebElement productName = driver.findElement(By.id("product-name")); assertEquals("Dell XPS 13", productName.getText()); // Set quantity WebElement quantity = driver.findElement(By.id("qty")); quantity.clear(); quantity.sendKeys("2"); // Add to cart WebElement addBtn = driver.findElement(By.id("add-cart")); addBtn.click(); // Verify cart updated WebElement cartCount = wait.until( ExpectedConditions.textToBePresentInElementLocated( By.id("cart-count"), "2" ) ); assertEquals("2", cartCount.getText()); }
OUTPUT: 🌐 Navigating to ecommerce.com 🔍 Searching for: Laptop ✅ Search results loaded 👆 Clicking first product 📦 Product: Dell XPS 13 ✍️ Setting quantity to 2 👆 Clicking Add to Cart ✅ Product added 🛒 Cart count updated: 2 ✅ TEST PASSED Time: 8.3 seconds
🔊 "Iframes là embedded pages trong main page. Nếu element ở trong iframe, Selenium không thể find nó từ main page. Bạn cần switch vào frame trước. driver.switchTo().frame(iframeElement) hoặc driver.switchTo().frame(frameIndex) hoặc driver.switchTo().frame(frameName). Ví dụ, website có iframe với id='payment-frame'. Bạn muốn find input field ở trong frame. Đầu tiên switch vào frame: driver.switchTo().frame(driver.findElement(By.id('payment-frame'))). Bây giờ bạn có thể find element ở trong frame: driver.findElement(By.id('card-number')). Sau khi done, switch out khỏi frame: driver.switchTo().defaultContent() back về main page, hoặc driver.switchTo().parentFrame() switch vào parent frame. Nếu có multiple nested iframes, bạn cần switch vào từng frame theo order."

🏆 Selenium Best Practices

1. Use Explicit Waits (Not Implicit)

  • ✅ Explicit: Fast, specific, reliable
  • ❌ Implicit: Slow, global, unreliable

2. Prefer ID Locators

  • 🥇 ID: Fast, unique, reliable (best)
  • 🥈 CSS: Flexible, fast (good)
  • ❌ XPath: Powerful but fragile (last resort)

3. Page Object Model (POM)

Tách elements & actions thành page classes:

// LoginPage.java public class LoginPage { WebDriver driver; private By usernameLocator = By.id("username"); private By passwordLocator = By.id("password"); private By loginLocator = By.id("login"); public LoginPage(WebDriver driver) { this.driver = driver; } public void login(String user, String pass) { driver.findElement(usernameLocator).sendKeys(user); driver.findElement(passwordLocator).sendKeys(pass); driver.findElement(loginLocator).click(); } } // Test.java LoginPage page = new LoginPage(driver); page.login("john@example.com", "password");

4. Handle Exceptions

try { WebElement elem = driver.findElement(By.id("element")); } catch (NoSuchElementException e) { System.out.println("Element not found"); } catch (StaleElementReferenceException e) { System.out.println("Element stale, retrying..."); }

5. Add Logging & Screenshots

// Take screenshot on failure File screenshot = ((TakesScreenshot)driver) .getScreenshotAs(OutputType.FILE); FileUtils.copyFile(screenshot, new File("screenshot.png")); System.out.println("✅ Step completed successfully");
🔊 "Alerts là popup windows - ví dụ confirmation dialog 'Are you sure?'. Nếu bạn cố find element ở alert, fail vì alert overlay page. Bạn cần switch sang alert object: Alert alert = driver.switchTo().alert(). Rồi bạn có 3 options. Thứ nhất: alert.accept() - click OK button. Thứ hai: alert.dismiss() - click Cancel button. Thứ ba: alert.sendKeys('text') - type text vào input field ở alert. Ví dụ, page show 'Enter your name' prompt. Code: Alert alert = driver.switchTo().alert(). alert.sendKeys('John'). alert.accept(). Sau khi accept/dismiss alert, control return về page. Bạn có thể continue làm action khác."

⚠️ Common Problems & Solutions

1. NoSuchElementException

Problem: Element không tìm được

Solution: Dùng explicit waits

// ❌ Bad WebElement elem = driver.findElement(By.id("dynamic")); // ✅ Good WebElement elem = wait.until( ExpectedConditions.presenceOfElementLocated(By.id("dynamic")) );

2. StaleElementReferenceException

Problem: Element reference không còn valid (DOM refreshed)

Solution: Re-find element sau page refresh

// ❌ Bad - element stale setelah refresh WebElement elem = driver.findElement(By.id("element")); driver.refresh(); elem.click(); // ❌ StaleElementReferenceException // ✅ Good - re-find after refresh driver.refresh(); elem = driver.findElement(By.id("element")); elem.click();

3. Element Not Clickable

Problem: Element ada tapi tidak clickable (covered by other element)

Solution: Scroll to element, dùng JavaScript click

// Solution 1: Scroll to element ((JavascriptExecutor) driver).executeScript( "arguments[0].scrollIntoView(true);", elem ); elem.click(); // Solution 2: JavaScript click ((JavascriptExecutor) driver).executeScript( "arguments[0].click();", elem );

4. Timeout Exceptions

Problem: Explicit wait timeout (element tidak load 10 detik)

Solution: Debug - inspect page, extend timeout, check selectors

🔊 "Ngoài cái mà Selenium support, bạn có thể execute JavaScript trực tiếp. Ví dụ, bạn muốn scroll tới element, hoặc bạn muốn hide element, hoặc bạn muốn inject data. JavascriptExecutor js = (JavascriptExecutor) driver. js.executeScript('script here', arg1, arg2, ...). Ví dụ, scroll element vào view: js.executeScript('arguments[0].scrollIntoView(true);', element). Highlight element (useful để debug): js.executeScript('arguments[0].style.border = "3px solid red";', element). Click element (alternative khi regular click fail): js.executeScript('arguments[0].click();', element). Get custom attribute: String value = (String) js.executeScript('return arguments[0].getAttribute("data-custom")', element). Nếu script return value, bạn cast vào appropriate type."
